Feature Summary

  • View EXIF: Inspect camera, lens, date, location, and file metadata in a readable layout.
  • Edit & Template: Apply metadata templates for credits, descriptions, copyright, and image organization.
  • Remove Private Data: Strip sensitive EXIF fields before sharing images publicly.
  • Cross-Platform: Built for Windows, Linux, and macOS workflows.

Photo Metadata FAQ

How to add metadata to photos?

Open your image in Gledhill Metadata, add or update the EXIF and descriptive fields you need, apply a saved template if useful, and export the organized result.

How to get metadata from a photo?

Load the photo and the app reads the embedded EXIF, file, camera, and organization metadata so you can review it before editing or removing anything.

How to see metadata of a photo?

Gledhill Metadata presents the photo metadata in a clean interface designed for quick inspection, privacy review, and repeatable image organization.
