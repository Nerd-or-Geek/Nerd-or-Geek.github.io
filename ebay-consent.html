Review and Grant Application Access: Nerd-or-Geek

Nerd-or-Geek uses eBay authorization to read seller inventory and offer data so the public Nerd or Geek Store page can show accurate listing cards. Checkout still happens securely on eBay.

Only approve access on an official ebay.com consent page. Nerd-or-Geek will never ask for or receive your eBay password.

What Access Is Used For

Inventory and Offers

Read published inventory items, offer status, listing IDs, product titles, prices, conditions, and product images for the Nerd or Geek eBay storefront.

Store Display

Refresh a static JSON file used by nerd-or-geek.org to display store listings without exposing eBay API keys in browser JavaScript.

Secure Checkout

Send shoppers to eBay for listing details, purchases, payment, shipping, and checkout. Nerd-or-Geek does not process payments on this website.

Permissions You May See on eBay

eBay may show a broad consent screen for the application. The current Nerd-or-Geek website workflow only needs seller inventory and offer access to generate public store cards.

  • View your inventory and offers.
  • View and manage your inventory and offers, when required by eBay for Inventory API access.
  • View basic account/store identity so listings can be tied to the correct seller account.
  • View eBay store information used to connect listings to the Nerd or Geek storefront.

Nerd-or-Geek does not use this static website workflow to read your eBay password, store payment credentials, or perform checkout outside eBay.

Managing Access

You can revoke Nerd-or-Geek access at any time from your eBay account settings under third-party app access. If access is revoked, the automated store listing refresh will stop working until authorization is granted again.
